`tkz-euclide` 是一个专为 LaTeX 设计的宏包，用于绘制二维欧几里得几何图形。它构建在 PGF/TikZ 之上，旨在让数学教师和学生能以接近手工尺规作图的自然方式，通过代码一步步构造几何图形。

### 核心定位与特点

它的设计哲学是“用语言描述作图”。你不需要像在纯 TikZ 中那样处理复杂的坐标计算，而是使用类似“定义点、画线、标记”的直观命令。

*   **面向教学**：作者 Alain Matthes 开发它的初衷，是让数学老师能快速创建准确的几何图，而无需深入学习全新的编程语言。
*   **专精几何**：与通用的 TikZ 不同，`tkz-euclide` 只专注于欧氏几何对象（点、线、圆、三角形、多边形等）。它的语法更贴合数学语言，例如定义中点、垂线、角平分线等操作都有现成的宏。
*   **底层兼容**：因为它基于 TikZ，你随时可以在文档中混用 TikZ 命令来补充细节（比如填充颜色），但作者建议不要过度混用，以免语法混乱。

### 基本用法与现状

*   **基本语法**：典型的命令结构是 `\tkzDefPoint`（定义点）、`\tkzDrawLine`（画线）、`\tkzLabelPoint`（标记点）等。例如，`\tkzDefMidPoint(A,B)` 会自动计算 AB 的中点，结果可通过 `\tkzGetPoint` 提取使用。
*   **版本与维护**：该包由 Alain Matthes 维护，采用 LPPL 协议。截至 2026 年 10 月，最新版本为 **5.14c**。近期更新主要集中在修复选项泄漏、精度计算等 Bug，语法保持稳定。
*   **环境要求**：它需要 UTF-8 输入的 LaTeX，可以在 pdfLaTeX 或 LuaLaTeX 下运行。在 TeX Live 和 MiKTeX 中均可直接安装使用。

如果你需要查阅具体的宏命令或完整示例，可以访问其官方手册页（tikz.dev/tkz-euclide）。
